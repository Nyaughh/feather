Read the repo. Make the commit.

Feather is a small, fast desktop app for looking through a repository and doing everyday git. It opens in a blink, shows you the files and what changed, lets you fix a line and commit it, and stays out of the way.

Needs git installed

Everything you need for the everyday. Nothing you don't.

The whole tree, with what changed

Open any folder and its files are on the left. Modified and new files are marked, ignored ones are dimmed, and big folders only load when you open them.

Read it, then fix it

Source is syntax highlighted and editable: click in, type, and save. Markdown is rendered, with a switch back to the raw text. Images and SVGs show as pictures.

Stage, commit, push

Staged and unstaged changes sit in two lists. Click one for its diff, stage or discard it, write a message and commit. Stash work for later, amend or undo the last commit, and pull, push and fetch right below.

Branches and worktrees, one click away

Both live in the bottom-left corner. Click to switch, including to a branch that so far only exists on the remote, or type a new name to create one.

Always up to date

Edit in another editor or run git in a terminal, and Feather shows the change within a couple of seconds. It also checks for new versions of itself and installs them when you say so.

Find anything

Search text across the whole repository, with matches listed by file. Find within the open file, or jump to a file by typing part of its name.

A terminal where you work

Open a terminal in the repository without leaving the window. Run the dev server in one tab and tests in another.

Themes for the whole app

Eight built-in themes, each with a light and a dark side. Or paste one from tweakcn or any shadcn/ui theme, and everything from the sidebar to the terminal follows it.

Native, not a browser in a box

One small program with nothing else to install. It draws with your graphics card, and when nothing is changing it does no work at all.

Edit, run, commit

Every file opens ready to type in, and CtrlS saves. A terminal sits underneath for the dev server or the tests, and the change is in the Git tab straight away, ready to stage.

A README that looks like one

Open a repository and Feather lands on its README, rendered with headings, tables, code blocks and images. Switch to Source to see the Markdown itself.

Search like you mean it

CtrlShiftF searches every file that isn't ignored, with options for case, whole words and regular expressions. Click a result and the editor opens on that line. CtrlP opens a file by name.

Make it yours

Pick a theme, or bring your own: paste the CSS from tweakcn and the whole app takes on its colours and corner radius. Then choose light or dark, an accent, the size of the interface and of code, and whether long lines wrap.

Install

From version 0.2 on, Feather offers new versions itself, so this is a one-time download. It uses the git you already have, so your hooks, signing and saved logins work as they do in a terminal. Install git first if you don't have it.

macOS

macOS 11 or newer, Apple silicon and Intel

  1. Open Terminal and paste this line: curl -fsSL https://feather.lh3k.dev/install.sh | bash
  2. It downloads the newest release, checks it against the published checksum, puts Feather in Applications and opens it. It asks for no password and changes no setting. You can read the script first.
  3. Why Terminal: Apple hasn't notarized Feather, and macOS refuses to open such an app when a browser downloaded it. A copy fetched this way isn't held back. This is not notarization, and the rest of macOS's protections still apply.

Or download the zip and drag Feather into Applications. If macOS blocks it, open System Settings > Privacy & Security > Open Anyway.

Windows

Windows 10 or 11, 64-bit

  1. Download the installer and run it.
  2. Windows shows a blue Windows protected your PC box, because Feather isn't code-signed yet. Choose More info, then Run anyway.
  3. Setup needs no administrator password. It adds Start menu and desktop shortcuts, and can add Open with Feather to the right-click menu for folders.
Download for Windows

Or the program on its own, with nothing to install.

Linux

64-bit Intel or AMD, Ubuntu 22.04 or a distribution as recent

  1. Download the archive.
  2. Unpack it: tar -xzf feather-linux-x86_64.tar.gz
  3. Run ./feather, or ./feather path/to/repo to open one directly.
